# spellingbeegetinvolved — แข่งคำศัพท์ ม.1–ม.6

เว็บสำหรับจัดแข่งเขียนคำศัพท์ภาษาอังกฤษ (ฟังแล้วเขียน) ระดับ ม.1–ม.6

- แต่ละชั้นมี 3 ชุด × 4 รอบ รอบละ 20 คำ (ไม่ใช้คำซ้ำ, ใช้คำเดี่ยว ไม่มีวลี/พหูพจน์)
- ลำดับต่อข้อ: Number → 2 วินาที → คำศัพท์ → 3 วินาที → คำศัพท์ → เวลาเขียน 20 วินาที (เสียงเตือนทุกวินาทีใน 5 วินาทีสุดท้าย)
- จบข้อ 20: ตรวจทาน 20 วินาที → เสียงนาฬิกา → วางปากกา
- ปรับความเร็วเสียงได้ 0.75× – 1.5×
- สัดส่วน ง่าย/กลาง/ยาก: รอบ 1 = 30/30/40, รอบ 2 = 20/40/40, รอบ 3 = 10/50/40, รอบ 4 = 0/60/40

## โครงสร้าง
- `index.html` — หน้ารวมชุดสำหรับฝึกซ้อม (ส่งให้นักเรียนได้)
- `practice/m1` … `practice/m6` — ชุดสำหรับฝึกซ้อม (3 ชุด × 4 รอบ + รอบฝึกเพิ่ม) มีปุ่มคัดลอกลิงก์
