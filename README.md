# Spelling Bee ม.1–ม.6 — การแข่งขันสะกดคำศัพท์ภาษาอังกฤษ

เว็บไซต์เดียวสำหรับการฝึกซ้อมและการแข่งขันสะกดคำศัพท์ (ฟังแล้วเขียน) ระดับชั้น ม.1–ม.6

- หน้าหลัก: https://pratchayapiw.github.io/spellingbeegetinvolved/
- ชุดสำหรับฝึกซ้อมรายชั้น: `practice/m1/` … `practice/m6/` (ส่งลิงก์ให้นักเรียนได้)
- หน้าหลัก (สำหรับครู): ทุกชั้นมีปุ่ม "ชุดแข่งขัน" (ใช้รหัสผ่านของชั้นนั้น) และ "ฝึกซ้อม" (`practice/` มีปุ่มคัดลอกลิงก์ส่งนักเรียน)
- ชุดแข่งขันสะกดคำศัพท์: รายการคำและไฟล์เสียงเข้ารหัส (AES-GCM) เปิดได้เมื่อกรอกรหัสผ่านเท่านั้น

รูปแบบ: 3 ชุด × 4 รอบ รอบละ 20 คำ · Number → 2 วินาที → คำศัพท์ → 3 วินาที → คำศัพท์ → เขียน 20 วินาที (เตือน 5 วินาทีสุดท้าย) · ปรับความเร็ว 0.75×–1.5×
